# CommuniCorp – Case 6-2 Capacity Concerns

Streamlit app that decides which intranet servers CommuniCorp should buy, and when, at minimum cost.

| | Plan | Total cost |
|---|---|---|
| **Part A** (month by month) | M2: 1 Desktop · M3: 1 Workstation · M4: 1 Mini Desktop · M5: 1 Desktop | **$22,500** |
| **Part B** (whole period) | M2: 1 Workstation (10% off, $9,000) · M3: 1 Workstation ($10,000) | **$19,000** |

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
